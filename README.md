# FIO的产品经理作品集

静态个人作品集，包含数字人平台、GTT 智能停车系统、植物 App 和企业 AI 产品方案案例。

## GitHub Pages

发布目录为仓库根目录。进入 Settings → Pages，在 Build and deployment 中选择 Deploy from a branch，分支为 main，目录为 / (root)，保存即可。

预计地址：https://fio923.github.io/portfolio/

以后修改 HTML、CSS、JavaScript 或图片并提交到 main 后，Pages 会自动更新。

## 本地浏览

直接打开 index.html，或在此目录运行 `python -m http.server 8000`。
